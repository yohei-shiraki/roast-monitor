片手鍋を使った手軽な焙煎の流れと、RoastMonitorで温度を記録しながら焙煎する方法を紹介します。 ここでは中浅煎り（ミディアムロースト）と、中深煎り（シティーロースト）についてそれぞれ説明します。 初めての方は、まず中深煎りをお試しいただき、焙煎に慣れてきたら中浅煎りに挑戦するのがオススメです。

Pan roasting

片手鍋焙煎のやり方

実際に焙煎を始める前に焙煎の大まかな流れを把握しましょう。

用意するもの

生豆

1回あたり100〜200g程度。鍋の底に薄く広がる量が扱いやすいです。

片手鍋とガスコンロ

蓋つきの片手鍋がおすすめです。豆が飛び出しにくく、火力も安定します。

ザルとうちわ

焙煎後すぐに豆を冷ますために使います。チャフを飛ばすのにも便利です。

軍手・ミトン

鍋は高温になります。やけど防止のため必ず手を保護してください。

手順

  1. 豆を量って鍋に入れる

    100〜200gの生豆を片手鍋に入れます。割れた豆や異物は取り除いておきます。

  2. 中火で予熱しながら攪拌する

    蓋をして中火にかけ、鍋をコンロから少し浮かせた状態で蓋を軽く押さえ前後に振ります。均一な焙煎には、鍋を振り続け豆を絶えず動かす事が重要です。 30〜60秒に一度振るのを止め、蓋を開けて中の豆の色や香り、様子を確認します。この時豆が焦げないよう5秒以内を目安に鍋の振りを再開してください。

  3. 1ハゼを聞く

    豆が黄色から茶色へ変わり、パチパチと弾ける音（1ハゼ）が始まります。煙とともに香ばしい香りが立ちます。1ハゼが聞こえ始めたらすぐコンロを弱火にしてください。 1ハゼの音は徐々に大きくなり30～60秒ほどでピークに達します。その後さらに30～60秒ほどかけて音は徐々に小さくなっていきます。 中浅煎りの場合、1ハゼの音が小さくなったタイミング（目安として豆の温度は200℃前後）で火を止めます。中深煎りより深く焙煎する場合、2ハゼが聞こえてくるまで焙煎を続けてください。

  4. 2ハゼを聞く（中深煎りより深く焙煎する場合）

    1ハゼが収まった後さらに加熱を続けると「ピチピチ」と細かく弾ける2ハゼが始まります。 中深煎りの場合、2ハゼが聞こえ始めたタイミング（目安として豆の温度は210℃前後）で火を止めます。

  5. 火を止めすぐに冷ます

    豆をザルにあけ、うちわで風を送って一気に冷まします。冷却が遅いと火が入りすぎるので素早く行います。

焙煎では器具や豆が高温になり煙が出ます。換気扇を回し、窓を開けるなど換気を十分に行ってください。また火傷にご注意ください。 鍋やコンロから目を離さず、火の取り扱いには十分注意しましょう。

How to use

RoastMonitorで焙煎を始める

RoastMonitorの設定と実際の焙煎について説明します。

用意するもの

RoastMonitor

焙煎の温度ロガーです。温度センサを取り付けているネジ部のゆるみが無い事を確認してください。

USB充電器・USB type-Cケーブル

RoastMonitorはUSB type-C から供給される電力で動作します。

WiFiネットワーク (2.4 GHz)

RoastMonitor は、2.4 GHz の WiFiに接続します。2.4GHzに対応したWiFiネットワーク（スマートフォンテザリング不可）をご用意ください。 詳細な設定方法はご使用の無線ルータ、アクセスポイント等の説明書をご覧ください。

緑色LEDの状態

RoastMonitorの状態は緑色LEDの点灯・点滅パターンで確認できます。

点灯

通常起動（WiFi接続済み）の状態です。

1秒周期で点滅

起動中（WiFiへ接続を試みている状態）です。

高速点滅

ネットワーク設定モードで起動している状態です。

ネットワークの設定をする

  1. ネットワーク設定モードでRoastMonitorを起動する（初回起動時もしくはネットワーク設定変更時のみ）

    1. Roast Monitor本体右下のUserボタンを押しながら、充電器に接続したUSB Type-CケーブルをRoast Monitorに接続して電源を投入します。
    2. 接続すると赤色LEDが点灯し、緑のLEDが1秒周期で点滅します。緑のLEDが高速で点滅を始めるまで数秒待ちます。
    3. 高速に点滅したらUserボタンを離してください。

  2. ネットワーク設定モードで起動したRoastMonitorにスマートフォンから接続する

    1. お持ちのスマートフォンのWiFi設定画面を開きます。
    2. 「RoastMonitorSetup」というSSID名のネットワークを探して接続します。
    3. 接続すると自動でRoastMonitorのネットワーク設定画面が開きます。開かない場合はWiFiセットアップ画面上のログインボタンを押してください。

  3. ネットワーク設定画面で使用するWiFiネットワークを設定する

    1. ネットワーク設定画面を開くと、自動で周囲のWiFiスキャンが始まります。スキャンが完了したら使用するWiFiのSSIDを選択し、パスワードを入力します。
    2. Saveボタンを押してください。Saveボタンを押すと、自動で接続テストが実施されます。
    3. 正常に接続が確認できると、リセットボタンが表示されます。
    4. リセットボタンを押すと、Roast Monitorが通常モードで再起動します。再起動中は緑のLEDが1秒周期で点滅し、WiFiへの接続が成功すると点滅から点灯に変わります。点灯したら次のステップに進みます。

    再起動後緑のLEDが高速に点滅している場合、WiFi接続に失敗しています。一度USB Type-Cケーブルを取り外し、再度ネットワーク設定モードでの起動からお試しください。

RoastMonitorを使って焙煎する

  1. 通常モードでRoast Monitorを起動する

    USB Type-CケーブルをRoast Monitorに接続し起動します。Userボタンの押下は不要です。
    設定済みのWiFiへ自動で接続し、接続が完了すると緑のLEDが点灯します。

  2. 通常モードで起動したRoast Monitorにスマートフォンからアクセスする

    お使いのスマートフォンから、このページ下部の 「RoastMonitorで焙煎を始める」セクション にある「今すぐRoastMonitorで焙煎を開始」ボタンからアクセスしてください。

  3. 参照プロファイルを選ぶ

    Selectボタンを押し、参考にする焙煎プロファイルを選択します。

    • 中浅煎り：Medium-Roastを選択してください。
    • 中深煎り：City-Roastを選択してください。
    • 表示しない：Noneを選択してください。
    • 過去の焙煎プロファイル：Customを選択し、該当のalogファイルを選択してください。過去の焙煎プロファイルは、焙煎終了後にSaveボタンで保存できる焙煎記録のファイルです（詳細は後述の「焙煎記録を保存する」を参照）。

  4. 焙煎を開始する

    温度センサの先端を、鍋の底面に触れないように豆の中へ差し込み、豆に触れている状態にします。 その後コンロの火をつけてからStartボタンを押し、温度の記録を開始します。

  5. 温度を見ながら焙煎する

    画面には BT（豆温度）と ΔBT（1分あたりの温度変化）が表示されます。 焙煎プロファイルと現在の温度を参考にしながら焙煎を進めます。参考プロファイルに対して温度の上昇が不十分な場合、コンロの温度を上げるか片手鍋を振る位置を熱源の近くにしてください。 温度の上昇が過剰な場合、コンロの火力を下げるか片手鍋を振る位置を熱源から離してください。

  6. 焙煎を終了する

    焙煎終了のタイミングでStopボタンを押し、記録を停止してください。

  7. 焙煎記録を保存する

    Saveボタンを押すと現在の焙煎結果がスマートフォンに保存されます。保存したファイルは、SelectボタンのCustomから読み込むことで次回以降の参考プロファイルとして使用できます。
